# Student Expense Tracker

A simple Android application developed to help users record, manage, and monitor their personal income and expenses.

## 📱 Project Overview

The Student Expense Tracker allows users to manage their financial transactions and view their income, expenses, balance, and monthly savings.

The project was developed as part of my university coursework to gain practical experience in Android application development, Java programming, and database management.

## ✨ Features

* User registration and login
* Add income and expense transactions
* Search transactions
* Edit existing transactions
* Delete transactions
* Calculate total income
* Calculate total expenses
* Calculate current balance
* Calculate monthly income, expenses, and savings
* Local data storage using SQLite

## 🛠️ Technologies Used

* **Java**
* **Android Studio**
* **SQLite**
* **Android SDK**

## 📂 Project Structure

The main application code is contained in the `app` module.
